# 工程光学刷题

在线使用：https://aysquid.github.io/Optics/

- 按章节/知识点或历年真题练习；答案与解析独立展开。
- 504道章节题库题目；2016—2026年369条真题记录。已完成第一轮全库答案与解析审查，确认内容已修订，来源不完整或仍有争议的内容保留待核对；参考答案不等于全部已经定论。
- 个人云端记录：使用Supabase私有空间，每台设备输入同一同步密钥一次，无需邮箱登录。密钥由站点所有者私下保存，不在此仓库。
- 支持离线记录、冲突处理与JSON备份迁移。
- 电子笔记：左侧打开章节列表，12份章节PDF按原版《几何光学》《物理光学》拆分。点击章节后才加载PDF，返回保留刷题位置、选项、筛选和答案展开状态；光学仪器对应现有八个小节，可直达相关页。
- PDF阅读器支持整章连续下滑、25%–400%直接输入缩放、Ctrl＋滚轮双向缩放、适宽、下载和沉浸模式；沉浸时收起顶栏与侧栏，保留浮动缩放/退出按钮，Esc可恢复界面；PDF.js 6.3.289随站点提供，采用Apache-2.0许可，见vendor/pdfjs/LICENSE。章节页码和来源摘要见data/electronic-notes.json。
- 首页/入场/授权视觉改编自[ZuoDev1/Index-Main-Web](https://github.com/ZuoDev1/Index-Main-Web)，保留原作者署名，接入光学学习模块。明日方舟及莱茵生命相关标识归权利方所有；非官方网站。
- 运行时依赖随仓库提供。Lottie-web使用MIT许可；详见vendor/rhine。

源码更新由本机工程build-static.mjs生成静态目录后发布。

## 考研英语

历年真题首页顶部可切换工程光学与考研英语；英语一、英语二各收录2010—2026年17份试卷，共1700题。沿用本机现有英语Markdown资料及 [LIziak112/structured-kaoyan-english](https://github.com/LIziak112/structured-kaoyan-english) 的原题结构；没有重复生成题库或评分标准，发布的结构化JSON不包含该项目的解析文本。

- 年份页侧栏按完形、阅读A/B/C/D、新题型、翻译、作文导航；桌面文章65%、题目35%，手机文章滚动与题目抽屉保持独立。
- 刷题模式分篇提交，套卷模式在新题型结束时提示统一批改；未答题先提醒，确认后按零分计入。选择时不直接揭晓答案。客观题得分与正确数量按题型竖排显示。
- 英语及光学真题都有可暂停、继续、重置的计时；英语记录使用独立云端命名空间，草稿及批改版本会保存。
- 云端记录面板可填写个人DeepSeek API Key，默认仅本次会话使用，可选择仅当前设备记住；密钥不进入进度同步或导出。主观题通过登录验证的Edge Function使用原题、原采分点、题图和现成作文标准进行AI估分。
- 后端设置见 [supabase/ENGLISH-SETUP.md](supabase/ENGLISH-SETUP.md)。前端不会模拟真实AI评分；后端未连接时保留草稿并显示错误。
