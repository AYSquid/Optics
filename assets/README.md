# assets —— 题目配图目录

网页会在这个目录下查找题目配图（题干图与解析图）。
统一按如下方式在题库中引用：

```
![图的说明](assets/文件名.png)
```

写在 `data/questions.json` 的 `stemImages`（题干配图）或 `analysisImages`（解析配图）里：

```json
"stemImages": [
  { "src": "assets/example.png", "alt": "图 1 光路图" }
]
```

几点约定：

- 只放**不包含解答标注**的图作为题干配图；带答案的图请裁掉或重绘后再放进 `analysisImages`。
- 图片不存在时网页会显示中文提示「配图资源缺失」并给出路径，不会白屏。
- 支持点击放大查看（会弹出全屏查看层，按 Esc 或点「关闭」收起）。
- 建议用 PNG，宽度 800～1600 px 之间，保证清晰又不会太大。
