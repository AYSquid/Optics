## 来源与整理说明

- **原卷 PDF**：GitHub 仓库 [Fantasia1999/kaoyanzhenti](https://github.com/Fantasia1999/kaoyanzhenti)（考场版，无水印），已保存于本目录 `raw/`。
- **2010–2025 题目与答案**：基于 GitHub 数据集 [LIziak112/structured-kaoyan-english](https://github.com/LIziak112/structured-kaoyan-english)（题目部分可自由使用）整理，剔除了详细解析，仅保留题干、选项与参考答案。
- **2026 题目**：由 2026 原卷 PDF 经视觉大模型 OCR 识别后校对整理；客观题答案与网上多处答案键交叉核对一致。
- 作文题图 / 图表见各科目目录下的 `assets/`，正文以相对路径引用。

## 使用提示

- **参考答案在每份文件末尾**，可先做题再对答案。
- **翻译题**（英一 Part C / 英二翻译）在参考答案区标注了**采分点 / 关键词**：英一给出带分值的采分片段，英二给出关键表达。
- **作文评分标准**见 [作文评分标准.md](作文评分标准.md)。
- 客观题答案区给出「题号 答案字母 · 选项内容」，即使选项顺序与某些出版物不同，也能明确对应到正确选项。
- 部分年份的选项排列顺序可能与个别出版物存在差异，属正常现象；以本文档所选内容与对应答案为准。
- 2026 年文本来自 OCR 识别，个别标点或拼写可能有细微误差，欢迎对照 `raw/2026*.pdf` 校对。
