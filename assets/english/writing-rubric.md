# 考研英语作文评分标准

> 来源：教育部学生服务与素质发展中心·研招网《考研英语写作评分标准及原则》（[原文](https://yz.chsi.com.cn/kyzx/en/200812/20081203/11232756.html)），并结合英语一/英语二大纲档位整理。英语一、英语二**通用**，仅大作文档位分数不同。

## 一、评分原则与方法

1. A、B 两节对写作能力的基本要求相同，一般评分标准对两节都适用，但评分侧重点不同：
   - **A 节（应用文）**：侧重**信息点的覆盖、内容的组织、语言的准确性、格式与语域的恰当**。允许使用提示语中出现过的关键词，但**直接照抄提示语中的词组或句子会被扣分**。
   - **B 节（短文写作）**：侧重**内容完整性、文章组织的连贯性、语法结构和词汇的多样性及语言的准确性**。
2. 评分时**先根据内容和语言确定所属档次**，再按该档要求在档内 1～3 分间调节。
3. **字数要求**：A 节约 100 词；B 节 160～200 词（英语二约 150 词）。文章长度不符合要求的，酌情扣分。
4. 拼写与标点属于语言准确性的一部分，视其对交际的影响程度扣分；**英、美拼写及词汇用法均可接受**。
5. 如**书写较差、影响交际，分数降低一个档次**。

## 二、档次与分数对应

| 档次 | 小作文 A 节（10 分） | 英语一大作文 B 节（20 分） | 英语二大作文 B 节（15 分） |
|:---:|:---:|:---:|:---:|
| 第五档 | 9–10 | 17–20 | 13–15 |
| 第四档 | 7–8 | 13–16 | 10–12 |
| 第三档 | 5–6 | 9–12 | 7–9 |
| 第二档 | 3–4 | 5–8 | 4–6 |
| 第一档 | 1–2 | 1–4 | 1–3 |
| 零档 | 0 | 0 | 0 |

## 三、各档具体描述

**第五档**：很好地完成了试题规定的任务。包含所有内容要点；使用丰富的语法结构和词汇；语言自然流畅，语法错误极少；有效地采用了多种衔接手法，文字连贯，层次清晰；格式与语域恰当贴切。对目标读者完全产生了预期的效果。

**第四档**：较好地完成了试题规定的任务。包含所有内容要点，允许漏掉一两个次重点；使用较丰富的语法结构和词汇；语言基本准确，只有在试图使用较复杂结构或较高级词汇时才有个别错误；采用了适当的衔接手法，层次清晰，组织较严密；格式与语域较恰当。对目标读者产生了预期的效果。

**第三档**：基本完成了试题规定的任务。包含多数内容要点；应用的语法结构和词汇能满足任务的需求；有一些语法及词汇错误，但不影响理解；采用了简单的衔接手法，内容较连贯，层次较清晰；格式和语域基本合理。对目标读者基本产生了预期的效果。

**第二档**：未能按要求完成试题规定的任务。漏掉或未能有效阐述一些内容要点，写了一些无关内容；语法结构单调、词汇项目有限；有较多语法结构或词汇方面的错误，影响了对写作内容的理解；未采用恰当的衔接手法，内容缺少连贯性；格式和语域不恰当。未能清楚地传达信息给读者。

**第一档**：未完成试题规定的任务。明显遗漏主要内容，且有许多不相关的内容；语法项目和词汇的使用单调、重复；语言错误多，有碍读者对内容的理解，语言运用能力差；未使用任何衔接手法，内容不连贯，缺少组织、分段；无格式与语域概念。未能传达信息给读者。

**零档（0 分）**：所传达的信息或所用语言太少，无法评价；内容与要求无关或无法辨认。

## 四、得分点提示（备考要点）

- **内容要点齐全**：应用文注意题目要求的每一条（如"说明原因 + 提出建议"），图画/图表作文要"描述 + 阐释寓意 + 评论"三要素齐全。
- **结构清晰**：三段式（引入—展开—结论）；使用衔接词（firstly / moreover / in conclusion）使层次分明。
- **语言准确多样**：主谓一致、时态、单复数；避免全篇简单句，适当使用从句、非谓语、被动等。
- **格式与语域**：书信/通知/邮件格式正确（称呼、正文、落款）；称呼与语气得体。
- **卷面**：书写工整，避免涂改；字迹潦草会影响交际并降档。
- **避免照抄**：可直接使用提示语中的关键词，但不要整句照搬题目。
